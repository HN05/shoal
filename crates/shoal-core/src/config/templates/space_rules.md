Load the `shoal` skill, or read `shoal skill`, before any other action.
Run `shoal done` only when you have no further work to do and you and your work are completely finished.
Name your space with `shoal rename` once you know what it is for.
When a call that combines a `shoal` command with other commands is refused, run the `shoal` command on its own before treating the action as refused.
