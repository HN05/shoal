Run `shoal ready` when a PR is ready.
Ask the user with `shoal questions ask`.
Resolve local review findings with `shoal review resolve`.
Set your status line with `shoal progress` at each milestone and when you are blocked.
Open a draft PR after your first push when `shoal config show` gives `[pr] draft = true`.
Give separate work its own space.
After your PR merges, watch its CI on the default branch: open a PR that fixes a failure, and finish once it passes or another PR merges after yours.
